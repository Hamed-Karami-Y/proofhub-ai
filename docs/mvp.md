ProofHub AI MVP Scope

Included

Wallet

* Web3 wallet connection
* Wallet address association with audit records

AI Audit

* Prompt submission
* AI provider execution
* AI response generation
* AI model metadata

Audit Record

* Audit ID
* Timestamp
* Wallet address
* AI model information
* Proof hash
* Blockchain transaction information
* Verification status

Blockchain

* Proof Registry smart contract
* Base Sepolia deployment
* Proof registration
* On-chain proof lookup

Verification

* Audit verification
* Proof hash verification
* On-chain existence verification
* Audit history


Excluded

The following features are outside the current MVP scope:

* Organizations
* Teams
* Roles and permissions
* Reputation
* Notifications
* Advanced analytics
* Multi-AI orchestration
* SDK
* Enterprise administration
* Production-scale access control


MVP Goal

The MVP demonstrates one complete and verifiable path:


AI Execution
     ↓
Audit Record
     ↓
Proof Hash
     ↓
Blockchain Anchor
     ↓
Independent Verification
